# Continent outlines

`earth-land.geojson` is Natural Earth's 1:110m physical land dataset.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

The application rasterizes these polygons locally into a softened geographic mask for the animated cloud shader. No external image service is required at runtime.
